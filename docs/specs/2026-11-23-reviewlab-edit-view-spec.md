# ReviewLab 编辑视图规格

状态：草稿，等审核。日期：2026-11-23。作者：学生 Huang Haoran（24101322D）。

这份文档只规定普通视图里点 Edit 之后的编辑视图。它补充 `2026-11-21-reviewlab-file-overview-spec.md` 和 `2026-11-12-reviewlab-requirements.md`。数据规则不变：标题去掉首尾空白后不能为空，最多 120 个码位；正文允许为空，最多 4000 个码位；掌握状态仍是卡片上的一个字段。

根目录里的 `reviewlab-edit-view.png` 是上一张示意图。它把两块都画得太小，四周空得太多，不作为这一版的样子。手稿是 `RecallLab-3.jpg`。

## 1. 这一屏在做什么

点 Dock 的 Edit 之后，这一层不再是「左边轮盘、中间卡片」。屏幕在顶栏之下分成左右两块，两块都占住剩余高度的大部分，宽度大约各一半。左边是卡片预览，右边是编辑板。文件夹、轮盘、圆环、收藏栏在这一屏里不出现。

顶栏留下：Search、当前层名字、面包屑和计数、主题开关。Dock 在编辑时收起，避免挡住编辑板左下角的保存按钮。

## 2. 进出的动画

进入和离开都要能看出来，大约 360ms，缓出。

进入：

- 文件夹、轮盘、圆环、收藏栏淡出并向左移走。
- 当前这张卡从屏幕中间滑到左半边。后面的牌仍只在它右边露出一条边，Card Swap 的叠放不变。
- 编辑板从右侧滑入，停在右半边。它的高度和卡片接近，都顶到剩余区域的大部分，不是浮在中间的小块。

离开：同一套动作倒放。Esc、编辑板右上角的关闭，都走离开。没保存的修改先问，见第 5 节。

360px 到桌面都要能完成。窄屏时两块上下叠：卡片在上，编辑板在下，各自仍占住一屏里能看清的高度，可以各自滚动。不出现横向滚动。

## 3. 左边：卡片预览

左边就是现在普通视图里的那张 FlipCard，不是另一套卡片。

- 正面是标题，反面是正文。点卡片在正反面之间切换。
- 后面的牌只向右露出一条边。拖动换卡的手势在这一屏关掉，避免和编辑抢指针。换卡用方向键，见第 6 节。
- 左下角仍是 Mastered 和 Not mastered。点它们立刻写入掌握状态，和普通视图相同。这不是编辑板里的字段。
- 预览和编辑板同步。正在看正面时，右边正在编辑的是标题；翻到背面时，右边正在编辑的是正文。点标题输入区，卡片回到正面。点正文编辑区，卡片翻到背面。
- 标题和正文在打字时立刻出现在对应的那一面，不必等保存。保存失败或取消时，卡片回到已保存的文字。

## 4. 右边：编辑板

编辑板是一块和卡片差不多大的白面板，圆角和阴影与卡片同一套。里面只有这一张卡的标题和正文。

### 4.1 多种样式的文字

手稿上写的 “warm tool kit” 对得上 React Bits 的 **Warm Tooltip**（https://reactbits.dev/micro/warm-tooltip ）。它是一组提示：第一下要等一会儿，旁边的提示接着就打开。它不是编辑器，不能用来打字。

React Bits 免费组件里没有富文本编辑器。正文今天存在卡片的 `body` 字段里，是一段纯文字，上限 4000 个码位。这一版不改表。

样式只做三种，都写进这段 `body`，用很短的 Markdown，不另建字段：

| 样式 | 写入 | 卡片背面 |
|---|---|---|
| 粗体 | `**文字**` | 粗体 |
| 斜体 | `*文字*` | 斜体 |
| 圆点列表 | 行首 `- ` | 圆点 |

工具条放在正文编辑区上方，三个按钮：Bold、Italic、List。按钮的说明用 Warm Tooltip。标题没有样式，标题仍是一行纯文字。

三种标记也算进 4000 个码位。超过上限不保存，并说明超了多少。卡片背面只认这三种，别的符号照原样显示。

若审核时不要样式，就去掉工具条和 Warm Tooltip，正文退回纯文字。其余各节不变。

### 4.2 保存按钮

保存放在编辑板左下角。

React Bits 里看过的动作按钮：Hold Button 要按住才确认，Slide Commit 要滑过去才确认，Sling Button 是弹射，Fuse Button 带一条可撤销的引信。保存是常做的动作，不该再加一道确认。

这一版用 **Specular Button**（https://reactbits.dev/components/specular-button ）。文案是 `Save`。没有改动时它不可按。保存中显示正在保存，成功后回到不可按，直到再改字。失败时按钮恢复可按，并在按钮旁边写出原因。

## 5. 关闭和未保存

右上角是关闭。Esc 同样关闭。

这一张卡的标题或正文和已保存的内容不同，就是未保存。这时关闭、按 Esc、或用方向键换卡，都先问：

`Save changes to “当前标题”?`

按钮是 Save、Discard、Cancel。Save 走第 4.2 节。Discard 丢掉这张卡上还没写进数据库的字。Cancel 留在编辑视图。标题不合法时，Save 不可用，并说明是空的还是超长。

没有未保存的修改时，关闭直接回到普通视图，焦点仍在刚才那张卡。

## 6. 换卡

ArrowRight 下一张，ArrowLeft 上一张，到头之后回到另一头。换卡后编辑板换成那一张的标题和正文，预览也换成那一张，正反面回到正面。

光标在标题或正文里时，方向键只移动光标，不换卡。Esc 在输入里先结束输入；编辑板还开着时，再按一次 Esc 才走第 5 节。

## 7. 不在这一版里

不改统计、搜索、禅模式、新建文件夹。不改掌握状态的含义。不在编辑板里改收藏。不做账号，不做图片和表格。

## 8. 请审核的两点

1. 正文的三种样式是否就按第 4.1 节写进现有的 `body`。不要的话，改成纯文字。
2. 保存按钮是否就用 Specular Button。想换成别的 React Bits 按钮，直接指出名字。
