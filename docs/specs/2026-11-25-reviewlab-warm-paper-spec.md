# ReviewLab 暖纸规格

状态：2026-11-25 按实现请求落地。作者：学生 Huang Haoran（24101322D）。

这份文档只规定颜色和卡片的厚度。它补充 `2026-11-21-reviewlab-file-overview-spec.md`。不改路由、数据、掌握状态的含义，也不改三个视图的结构。统计清单点一条去普通视图，仍以文件概览规格第 7 节为准，不在这里重定。

界面按这一份改。审核时仍用第 5 节。

## 1. 为什么改

现在页面和卡片共用同一个白底，蓝色几乎只出现在焦点上，绿和红是画面里仅有的颜色。卡片已经能翻转，后面的牌也只向右露出一条边，但牌面仍是一条细线和一团模糊阴影，读起来像贴在屏幕上。

要的是一叠纸，不是灯，也不是一块厚板。学习时要反复看题干，高光和挤出来的侧面都会挡字，也会和现有的翻转、拖出页面打架。

## 2. 纸色

页面和卡片分开。页面是暖纸，卡片比页面亮一档。字用暖墨色，不用纯黑、纯白。

一个赭石色只回答「你在哪」。它只出现在三处：键盘焦点环、底部栏里正在用的视图、选中的文件夹边。不涂在正文、掌握按钮、圆环、状态圆点、删除上。

掌握仍是绿，未掌握仍是红，只是往这套纸色里靠。空心圆点和文字标签都留着，颜色不是唯一线索。收藏的星仍是现在的 `#f0a500`，不再加一个相近的黄。

深色单独配一套暖黑，不把浅色反过来。

正文和次要文字在卡片底上至少 4.5:1。大标题至少 3:1。两套主题都要量过，不能只看浅色。

掌握的绿和红今天写在文件视图、禅模式、统计、圆环和轮盘里。落地时收成上面两个令牌，不要再各写一遍。

`--rl-surface` 今天同时当页面和卡片。落地时页面改用 `--rl-canvas`，卡片、搜索层、对话框继续用 `--rl-surface`。禅模式、底部栏、编辑板里各自写死的灰也改到这套令牌上，否则那些屏还是冷灰。

## 3. 厚度

材料是一叠短的卡片纸。普通视图、编辑视图、禅模式用同一套，不另做一种牌。

每张牌两层影子：

- 贴边：大约 `0 1px 2px`，颜色是墨色，很淡。它说明纸边碰着桌面。
- 远处：留下现在那团软阴影，颜色改成同一支墨，不要再加一圈均匀的灰雾。

牌的上沿加一条约 1px 的亮边。浅色里它比牌面略暖、略亮。深色里用大约 8% 的暖白，避免 `#101014` 那种冷灰边发亮。

向右露出的下一张牌，在露出的那一条上加约 2px 的深边，读成下一张纸的侧面。不把那一条画成又一张完整的卡。叠放仍只向右，前面那张仍盖住后面的。

拖动时远处的影子变长、变淡，表示这张被拿起来。松手回到原位或换到下一张时，影子回到静止的高度。点击翻面的逻辑不变，拖动仍跟着手指。

圆环不挤出厚度。轨道底下垫一笔同样颜色的暗线，绿仍是绿，红仍是红。

底部栏用和卡片一样的贴边阴影，底边加一条 2px 的暗唇。编辑板用和左边卡片同一套影子和亮边，两块看起来是同一种纸。

统计页的清单仍是文字行，不加牌的厚度。悬停只换底色。

`prefers-reduced-motion: reduce` 时不做影子变长。静止的厚度留下。

## 4. 明确不做

- 不在牌面上打一束固定的光。高光会盖住题干，深色里会把字洗掉。
- 不把牌的侧面真的挤出几像素。它会和翻转、拖出页面打架，窄屏上也会吃掉右边露出的那一条。
- 不做玻璃、不做软泥浮雕。
- 不做孔版印刷那种硬边错位，也不把掌握换成钴蓝和珊瑚。绿和红的含义不动。
- 不把圆环做成甜甜圈，不给清单加图标或外框。

## 5. 审核时看什么

浅色和深色各看一遍普通视图、编辑视图、禅模式、统计。

- 页面比卡片暖、比卡片暗一档，卡片仍是画面里最亮的纸。
- 赭石只出现在焦点、当前视图、选中的文件夹。
- 掌握是绿，未掌握是红，未标记仍是空心点，三种靠形状也能分开。
- 右边露出的牌能看出是下一张纸的边。
- 拖一张牌，影子跟着抬起，松手落回。
- 窄到 360px 时没有横向滚动，题干仍可读。
